A single line of error copy for a dead database: it names the outage in plain words, tells the user to retry in a few minutes, and softens the bad news with a joke about the database's very long coffee break. Written to be pasted into a real product's error dialog without embarrassing the team behind it.

## Run it

```sh
python3 main.py
```
